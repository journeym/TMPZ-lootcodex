TMPZ-LootCodex lets you search every item on the server and see where it comes from: which mob drops it, which boss, which quest, which vendor, or which recipe crafts it. It’s built for Epoch’s classic-style items, so the TBC/WotLK leftovers the server still knows about are hidden. It also fills in Epoch’s & Reborns custom content as you and your guild & party play.

The addon will run an update run once a day, this could cause some items to not display correctly during the scan - after the first scan it's quicker

Features

Item search: filter every item by slot, stats, level and source. Tabs for Equipment, Consumables, Professions, Dungeons, Sets, Quest Items and more.

Where it comes from: drops (with chances), dungeon and world bosses, crafting, quest rewards, vendors, reputation, world events and PvP.

Tooltips: item tooltips show where the item comes from. Hover a mob to see what it drops, best chance first. Hold Ctrl for the full list, and Ctrl + mouse wheel scrolls it.

Upgrade finder: arrows show whether an item is better or worse than what you’re wearing, scored for your spec. It also marks the best quest reward. WIP - Will update

Wishlist: save the items you’re after. You get an alert when one is in a loot window or up for roll. You also get an alert when you target or fight a mob that drops one, and a star appears on its portrait.

Show on map: pins where an item drops on the world map. Needs pfQuest.

Learns as you play: records what you loot, what vendors sell and quest rewards. It can share them with guild and group members who also use the addon, so Epoch’s custom mobs and items get filled in over time.

Recent tab: items you’ve looked at or opened from chat links.

Installing

Copy the two folders, TMPZ-LootCodex and TMPZ-LootCodex_Data, into World of Warcraft\Interface\AddOns\.

Optional but recommended: install pfQuest-wotlk and pfQuest-epoch for mob drops, vendors and map pins.

Restart the game. A /reload isn’t enough for new addons.

Using it

Type /codex or click the minimap button to open the window.
/codex sword of searches every item straight away.

Right-click an item in the list to add it to your wishlist, show it on the map, or link it in chat.
Hover any mob to see its drops.

Right-click the minimap button, or type /codex settings, for all the options. Every feature can be switched off on its own.

Handy commands

/codex help: lists all commands.
/codex wishcheck: does your current target drop anything on your wishlist?
/codex update: checks the server for new or changed items.
/codex status: shows which helper addons were found and what has been learned.
